05 — Import Verified Historical Results

Import a JSON file containing historical result records. Each record must identify the horse, date, centre, distance, finishing position, field size and a verified source. Individual horse times are optional. Race-level times are never treated as individual horse times.

Build the race cards first, then import verified historical records to attach evidence to matching runners.

Import format: a JSON array of records, or an object with a "records" array. Every record requires a verified source name. Horse-name matches are provisional until identity is confirmed; similar names must not be assumed to be the same horse.
